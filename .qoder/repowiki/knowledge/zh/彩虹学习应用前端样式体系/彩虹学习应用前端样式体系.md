本仓库采用 Tailwind CSS v4 + Vite 构建儿童学习应用的视觉风格，通过设计令牌（Design Tokens）与动画系统实现统一的彩虹主题。

## 1. 技术栈与工具链
- 样式框架: Tailwind CSS v4（@tailwindcss/vite 插件），无传统 tailwind.config.js，所有配置内联于 CSS
- 动画库: Framer Motion（组件级动效）+ CSS Keyframes（背景装饰动画）
- 构建工具: Vite + React 19，路径别名 @/ 指向 src/

## 2. 设计令牌体系（Design Tokens）
核心令牌定义在 src/index.css 的 @theme 块中：
- 彩虹主色: --color-rainbow-red/orange/yellow/green/blue/purple (#FF6B6B ~ #9B59B6)，用于品牌渐变、导航高亮
- 业务色: --color-gem-gold (#FFD700)，宝石奖励计数
- 背景色: --color-bg-warm (#FFFBF5)、--color-bg-card (#FFFFFF)，页面/卡片背景
- 文本色: --color-text-primary (#2D2D2D)、--color-text-secondary (#6B7280)，主次文字
- 反馈色: --color-correct (#10B981)、--color-wrong-soft (#A78BFA)，对错状态
使用方式: bg-bg-warm、text-text-primary、from-rainbow-blue to-rainbow-purple 等 Tailwind 类名直接映射。

## 3. 响应式策略
- 移动端优先：基础字体 16px，min-width: 768px 时提升至 18px
- 安全区域适配：.safe-top/.safe-bottom 工具类处理刘海屏/底部横条
- 触摸优化：全局 -webkit-tap-highlight-color: transparent、touch-action: manipulation、overscroll-behavior: none

## 4. 动画系统分层
- CSS Keyframes（静态装饰）：漂浮云朵、星星闪烁、糖果飘落等循环动画，通过 .animate-float-slow、.animate-star-pulse 等类复用
- Framer Motion（交互反馈）：按钮点击缩放、选项卡弹入、进度条填充、粒子爆炸等用户驱动动效

## 5. 组件样式约定
- 圆角统一：大量使用 rounded-full 营造亲和感
- 渐变按钮：bg-gradient-to-r from-rainbow-blue to-rainbow-purple 作为主操作按钮标准样式
- 阴影层级：shadow-md（默认）、shadow-lg（悬停/激活）、shadow-inner（进度条轨道）
- 状态语义化：OptionCard 等组件通过 state 属性切换颜色/缩放，而非硬编码 class

## 6. 开发者规范
- 新增颜色必须加入 @theme 令牌，禁止在组件中写死色值
- 背景装饰动画优先复用现有 keyframes，避免重复定义
- 按钮最小高度 min-h-[52px] 确保儿童手指触控友好
- 移动端禁用橡皮筋滚动，保持沉浸式体验
