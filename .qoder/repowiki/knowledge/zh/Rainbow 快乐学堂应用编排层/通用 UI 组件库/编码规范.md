- 所有交互元素（按钮、卡片、头像）均设置最小触摸目标尺寸（如 min-h-[48px] 或 min-w-[80px]），以适配儿童用户的触控操作。
- 组件样式严重依赖 Tailwind CSS 的工具类组合，特别是自定义语义化颜色变量（如 bg-rainbow-red, text-gem-gold）以保持品牌视觉一致性。
- 动画效果通过 framer-motion 的 props（initial, animate, transition）直接在 JSX 中定义，而非提取到独立的动画配置文件。
- 状态驱动的样式切换采用对象映射模式（如 OptionCard 中的 stateStyles），将状态字符串映射为完整的 Tailwind 类名组合。
