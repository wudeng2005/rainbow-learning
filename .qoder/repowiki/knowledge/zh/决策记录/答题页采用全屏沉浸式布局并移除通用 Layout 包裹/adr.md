# 答题页采用全屏沉浸式布局并移除通用 Layout 包裹

_来源：dd02dbe → ab20740 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
原有的答题页面嵌套在包含顶栏和底部导航的通用 Layout 中，导致可用空间被挤压（pb-24 不足），且导航元素干扰了面向 5-7 岁儿童的专注学习体验。

## 决策驱动
- 最大化屏幕可用面积
- 减少视觉干扰以提升儿童专注度
- 避免底部导航遮挡答题内容

## 备选方案
- **修改路由配置使 /learn 不使用 Layout 包裹** — 优点：彻底隔离布局上下文，代码结构清晰，无额外边距困扰；缺点：需在 LearnPage 内部独立实现返回按钮等导航功能
- **保留 Layout 包裹，仅在 LearnPage 内使用 min-h-dvh 全屏容器** _（已否决）_ — 优点：改动较小，复用现有路由结构；缺点：仍需处理 Layout 带来的固定头部/底部占用空间问题，可能导致布局复杂化

## 决策
选择让 `/learn` 路由脱离通用 Layout 包裹，采用全屏沉浸式布局。LearnPage 将自行管理顶部返回按钮和整体容器，以确保最大的内容展示区域和无干扰的交互环境。

## 影响
答题页面获得完整的视口控制权，消除了导航栏遮挡风险。但需要在 LearnPage 中重新实现原本由 Layout 提供的通用导航元素（如返回按钮），增加了该页面的局部复杂度。
