模块以 `MathLearnPage.tsx` 为单一编排入口，内部通过 `renderQuestion` 的 switch 分发将题目数据路由到 `components/math/` 下的各 `*Renderer` 组件（Pattern/Counting/Comparison/Shape/Arithmetic/WordProblem/NumberSequence），实现按题型解耦的视图层。

- 状态管理：`useMathLearningStore.ts` 基于 zustand + persist 中间件维护 `dailyProgress`、`todayQuestions`、`currentIndex`、`sessionAnswers`、`mathDayIndex` 等字段，按 day 序号从 `math-questions.json` 中筛选当日题目并限制为 10 题；`partialize` 仅持久化进度相关字段，避免序列化整个题库。
- 数据驱动：题目全部来自 `src/data/math-questions.json`（约2万行，含 id/subject/type/difficulty/day/prompt/data/options/answer），鼓励语来自 `math-encouragements.ts` 的随机消息池，渲染器只消费 JSON 结构，不关心数据来源。
- 交互反馈：页面级 `optionStates` 数组驱动选项卡片状态机（idle/correct/wrong/disabled/reveal），通过 `setTimeout(150ms)` 延迟弹出 `MathFeedbackOverlay`，形成「先变颜色 → 再弹全屏」的节奏；完成时调用 `useGemStore.addGems` 发放宝石奖励。
- 辅助组件：`MathOptionCard` 提供统一的多态样式与 spring 动画，`MathProgressBar`、`MathDailyComplete`、`MathFloatingDecorations` 负责 UI 骨架与装饰。
