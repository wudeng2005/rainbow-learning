- 所有 Renderer 组件遵循统一 Props 契约：接收 data、options、optionStates 与 onSelect(index)，由父页面集中计算答案正确性后再下发状态，保持业务逻辑与视图解耦。
- 选项卡片通过 index % colors.length 取模自动分配 pastel 背景色，无需为每个选项硬编码样式，保证视觉多样性与代码简洁。
- 反馈采用两阶段时序：先同步更新 optionStates 触发卡片变色，再通过 setTimeout(150ms) 延迟显示 MathFeedbackOverlay，确保用户先感知局部反馈再看到全局结果。
- 题目数据以 JSON 文件集中定义并按 day 字段分组，store 使用 DAILY_QUESTION_COUNT=10 与 MAX_DAY=90 常量控制每日题量与总进度上限，新增题型只需在 JSON 追加并在 renderQuestion 分支注册对应 Renderer。
