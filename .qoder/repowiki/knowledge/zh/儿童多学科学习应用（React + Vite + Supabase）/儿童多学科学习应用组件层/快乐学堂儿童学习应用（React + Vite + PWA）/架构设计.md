- 启动编排：`main.tsx` 注册 Service Worker 实现离线缓存与弱网秒开；`App.tsx` 根节点调用 `useAppInit`，在渲染后立即返回 true（Zustand persist 已自动从 localStorage 恢复），随后后台异步执行迁移→拉取→注册可见性监听三步；支持 `?reset=YYYY-MM-DD` URL 参数一键重置。
- 路由隔离：答题类页面 `/learn`、`/math-learn`、`/english-learn` 独立挂载以独占全屏交互空间，其余功能页（首页、宝石、复习、个人主页）包裹于 `Layout` 共享底部导航；所有非首页使用 `lazy()` + `<Suspense>` 懒加载。
- 状态契约：各学科页面仅通过对应 Store（`useLearningStore` / `useMathLearningStore` / `useEnglishLearningStore` / `useGemStore` / `useErrorBankStore` / `useUserStore`）读写数据，不直接访问网络或文件系统；`src/lib/db` 暴露的 `fetch*` 与 `SyncManager` 是唯一的持久化入口。
- 资源分层：`src/data/*.json` 提供静态题目与鼓励文案，`src/components/{chinese,english,math}` 按学科拆分专用渲染器，顶层 `components/` 存放通用 UI（布局、进度条、选项卡、反馈弹窗等）。
