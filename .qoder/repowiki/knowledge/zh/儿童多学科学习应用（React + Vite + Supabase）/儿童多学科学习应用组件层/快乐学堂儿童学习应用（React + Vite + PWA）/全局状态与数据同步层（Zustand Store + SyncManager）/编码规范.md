- 每个 Store 都导出同名 `create(persist(...))` 实例并以 `rainbow-*` 作为 localStorage key，暴露 `hydrate(data)` 方法供初始化阶段从云端数据覆盖本地状态。
- 涉及云端数据变动的操作（答题、获得宝石、错题库更新）在 `set` 更新本地状态后立即调用 `syncManager.addPending*` 入队，而非直接发起网络请求。
- Store 内部使用函数式 `set(state => ({ ...state, ... }))` 进行不可变更新，避免直接修改 state 引用。
- 每日进度按 day 序号（1-90）顺序推进，完成当天后 `chineseDayIndex`/`mathDayIndex`/`englishDayIndex` 自增并在 `nextQuestion` 末尾触发 `syncAfterSession`。
