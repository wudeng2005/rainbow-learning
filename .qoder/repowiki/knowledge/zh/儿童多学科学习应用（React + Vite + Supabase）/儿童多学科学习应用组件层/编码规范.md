- 所有可交互按钮均使用 `motion.button` 配合 `type: 'spring'` 物理弹簧过渡，点击时 `whileTap={{ scale: 0.93~0.95 }}` 模拟按压回弹。
- 选项卡片采用 `index % cardColors.length` 循环分配柔和背景色（pink/blue/green 或 sky/cyan/indigo 等），并通过 stateStyles 对象集中映射 idle/correct/wrong/reveal/disabled 五种视觉态。
- 正确反馈统一在右上角/左下角以绝对定位叠加 emoji（⭐🍬✨🎉）装饰，配合 `initial={{ scale: 0 }}` 到 `scale: 1` 的延迟弹出动画强化正向激励。
- 错误反馈使用 x 轴抖动序列 `[0,-4,4,-2,2,0]` 配合 scale=1 的 shake 动画，与 correct 的 scale 放大形成对比。
- 完成页与教学页使用 `AnimatePresence mode='wait'` + key 驱动的入场/退出过渡，元素按 delay 阶梯式出现以营造节奏感。
