根目录作为 Vite/React 单入口，`src/main.tsx` 启动应用后由 `App.tsx` 根据当前学科切换 LearnPage/MathLearnPage/EnglishLearnPage/LearnPage(Chinese)；各学科组件位于 `src/components/{math,english,chinese}/`，共享 `src/components/` 下的通用 UI（Layout、ProgressBar、OptionCard、FeedbackOverlay、FloatingDecorations 等）。状态层集中在 `src/store/`：`useLearningStore` 为中文、`useMathLearningStore` 为数学、`useEnglishLearningStore` 为英语，`useUserStore` 负责用户信息，`useGemStore` 管理宝石积分，`useErrorBankStore` 维护错题本；所有 store 均通过 `src/lib/storage.ts` 的本地优先策略读写 IndexedDB/LocalStorage，并在初始化时调用 `src/lib/supabase.ts` 与云端同步。资源方面，`public/audio/` 按学科子目录组织 mp3（chars/correct/wrong/en/*、stories），`scripts/` 提供批量生成题目与音频的 Python 工具链，`src/data/` 存放 JSON 题库与角色配置，`vibe_images/` 与 `tmp-slide/` 为设计素材暂存区。
