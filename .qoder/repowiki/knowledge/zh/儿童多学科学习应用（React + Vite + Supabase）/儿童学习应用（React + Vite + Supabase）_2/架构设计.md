顶层入口 src/main.tsx → App.tsx 使用 react-router 按学科分发到 LearnPage / EnglishLearnPage / MathLearnPage，各页面再组合对应 components/{chinese,english,math} 下的渲染器；状态统一由 src/store 下多个 Zustand store（useLearningStore、useEnglishLearningStore、useMathLearningStore、useErrorBankStore、useGemStore、useUserStore）管理，并通过 src/lib/supabase.ts 共享的 Supabase 客户端读写云端数据；静态资源（mp3 音频、图片）放在 public/ 下由 Vite 直接提供，scripts/ 中的 Python 脚本负责生成 data/*.json 和 public/audio/* 等素材，src/data/ 作为所有学科共享的数据源。
