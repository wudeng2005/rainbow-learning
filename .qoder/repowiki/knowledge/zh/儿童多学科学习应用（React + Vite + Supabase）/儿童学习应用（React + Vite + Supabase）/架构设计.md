根模块作为应用入口，由 src/main.tsx 启动 Vite 开发/构建管线，src/App.tsx 统一注册路由并挂载各学科页面：LearnPage（数学）、EnglishLearnPage（英语）、HomePage/LearnPage（中文故事/生字）。跨子模块的协作契约集中在三层：
- 状态层：Zustand store（useLearningStore / useMathLearningStore / useEnglishLearningStore / useGemStore / useErrorBankStore / useUserStore）是全局唯一数据源，所有页面组件通过 hooks 订阅，避免 props 穿透。
- 持久化层：lib/db/supabase.ts 提供 Supabase 直连客户端，lib/storage.ts 封装 localStorage 缓存，store 初始化时先读本地再拉远端，形成“本地优先”混合架构。
- 资源层：public/audio 按 chars/correct/wrong/en/stories 等目录组织 mp3 素材，scripts/ 下的 generate-*-audio.py 脚本在构建前批量生成音频与题目数据，src/data/*.json 为静态题库与鼓励语。
- 布局约定：通用 Layout 包裹非答题页；/learn 路由使用全屏沉浸式容器以适配儿童交互，动画统一采用 CSS animation 而非 Framer Motion。
