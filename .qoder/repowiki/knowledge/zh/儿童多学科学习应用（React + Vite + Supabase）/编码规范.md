- 每个学科在 `src/components/{math,english,chinese}/` 下独立组织组件，同时复用 `src/components/` 中的通用 UI 组件
- 状态管理采用 Zustand Store 模式，每个学科一个独立 store（useLearningStore/useMathLearningStore/useEnglishLearningStore），用户与积分等跨学科状态单独拆分
- 数据持久化遵循本地优先策略：先读写 IndexedDB/LocalStorage（storage.ts），再异步同步到 Supabase（supabase.ts）
- 多媒体资源按学科分类存放在 `public/audio/` 对应子目录，命名遵循语义化规则（如 chars/correct/wrong/en/*）
- 题库与静态数据集中存放在 `src/data/*.json`，由 `scripts/` 中的 Python 工具链批量生成
