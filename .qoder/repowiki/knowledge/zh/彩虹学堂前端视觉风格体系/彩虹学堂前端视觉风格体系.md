## 样式系统概览

本项目采用 Tailwind CSS v4 + 原生 CSS 变量主题的混合方案，构建面向儿童的「云上梦乐园」视觉风格。

### 核心架构

- 样式框架：Tailwind CSS v4（通过 @tailwindcss/vite 插件集成），使用 @import "tailwindcss" 引入
- 设计令牌：在 src/index.css 中通过 @theme 块定义全部设计 token，包括彩虹调色板、天空渐变、基础色板和字体族
- 动画系统：纯 CSS @keyframes 实现，无 JS 动画库依赖（除 Framer Motion 用于页面过渡）

### 视觉约定

1. 玩具质感卡片：.toy-card 类统一使用 3px 深色边框 + 硬阴影，模拟积木/贴纸触感
2. 安全区域适配：提供 .safe-top/.safe-bottom 工具类处理刘海屏
3. 移动端优化：禁用橡皮筋效果、触摸高亮、dvh 兼容回退
4. 氛围背景：DreamBackground.tsx 组件用 CSS Animation 实现云朵漂移、星星闪烁、热气球上升等场景元素

### 组件级样式模式

- 各学科页面拥有独立的浮动装饰组件（FloatingDecorations.tsx、MathFloatingDecorations.tsx、EnglishFloatingDecorations.tsx）
- 统一的反馈动画：.animate-star-pulse、.animate-float-*、.animate-drift-*、.animate-candy-fall-*
- 字体规范：标题使用 font-display，数字使用 font-num

### 开发者约束

- 颜色必须使用 text-rainbow-* / bg-rainbow-* 等语义化 Token，禁止硬编码十六进制值
- 新动画应添加到 index.css 的 @keyframes 区块并导出对应 utility 类
- 卡片组件统一复用 .toy-card 基础样式，仅覆盖必要差异
- 所有装饰性动画设置 pointer-events-none 避免干扰交互
