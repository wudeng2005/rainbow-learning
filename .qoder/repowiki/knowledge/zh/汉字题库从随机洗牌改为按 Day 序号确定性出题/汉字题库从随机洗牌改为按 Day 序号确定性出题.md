# 汉字题库从随机洗牌改为按 Day 序号确定性出题

_来源：d227402 → 2e78b97 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
原有30题仅2种题型且依赖 emoji 象形字，需扩展到900题覆盖300个一年级常用汉字，要求90天不重复、循序渐进，并新增听音选字等题型。

## 决策驱动
- 每日题目确定性便于家长了解进度
- 按难度递进符合儿童认知发展
- 去重由算法保障而非运行时状态

## 备选方案
- **保持随机洗牌 + recentQuestionIds 去重** _（已否决）_ — 优点：实现简单；每次练习有新鲜感；缺点：无法保证90天完整覆盖；无法控制难度递进；近期去重在大数据量下性能下降
- **按 day 序号顺序取题 + 程序化生成题库** — 优点：天然去重；严格按阶段递进；每天10题固定节奏；支持90天完整规划；缺点：失去随机性；需维护900题数据；Day 结束后需处理完成态

## 决策
重构抽题逻辑：移除 `recentQuestionIds`，引入 `chineseDayIndex` 状态，`startDailySession` 按 `q.day === chineseDayIndex` 过滤当日10题；通过 Python 脚本生成900题 JSON 并按 Phase 1/2/3 分配 day 范围；新增 `char_to_pinyin`、`pinyin_to_char`、`char_to_word`、`char_to_meaning` 四种题型。

## 影响
学习路径完全确定，家长可精确追踪孩子进度。题库体积增至约100-150KB，音频文件约300-600KB，构建时打包可接受。90天完成后需实现复习模式或提示完成的降级策略。
