# 答题页面采用全屏沉浸式布局以优化儿童交互体验

_来源：cbee9d5 → 026352a 提交周期内记录的编码计划——内容为规划时意图，实现可能滞后或有出入。_

**状态：** accepted

## 背景
原有答题页嵌套在包含顶栏和底部导航的 Layout 中，导致可视空间受限且存在元素遮挡风险。针对 5-7 岁目标用户，需要更大、更清晰的视觉焦点和更简单的交互路径。

## 决策驱动
- 最大化可视区域
- 降低认知负荷（去除无关导航）
- 增强视觉反馈（大色块、动画）

## 备选方案
- **保留 Layout 包裹并调整内边距** _（已否决）_ — 优点：保持全局导航一致性；缺点：压缩答题核心区域，存在遮挡风险，分散儿童注意力
- **全屏沉浸式布局（选中方案）** — 优点：最大化题目与选项展示空间，消除导航干扰，便于实现夸张的动画反馈和装饰元素；缺点：需在页面内独立实现返回逻辑，脱离全局导航框架

## 决策
将 /learn 路由配置为不使用 Layout 包裹，采用 min-h-dvh 全屏容器。移除顶部顶栏和底部导航，改为页面内自带返回按钮。引入 FloatingDecorations 组件添加纯装饰性动画元素，并将进度条重构为星星连线形式，选项卡片采用大号圆润设计配合彩色渐变边框。

## 影响
显著提升了低龄用户的专注度和交互清晰度，但增加了单个页面的布局独立性，需确保返回逻辑和状态管理在全屏模式下依然健壮。
