开发：`npm run dev` 启动 Vite 热更新；构建：`npm run build`（先 tsc -b 再 vite build）；生成汉字题库：`python scripts/generate-chinese-questions.py` → 输出 `src/data/questions.json`；生成鼓励语音：`python scripts/generate-audio.py` → 输出 `public/audio/{correct,wrong}/*.mp3`；生成汉字读音：`python scripts/generate-char-audio.py` → 输出 `public/audio/chars/*.mp3`。
