- 所有可持久化的 Zustand store 使用 `persist({ name: 'rainbow-*', partialize })` 命名空间隔离，仅序列化必要字段（如 dailyProgress、todayQuestions、recentQuestionIds）。
- 题目数据结构以 JSON 文件集中维护（`questions.json`、`math-questions.json`），运行时通过 `as unknown as Xxx[]` 强转类型，禁止在业务代码中硬编码题目内容。
- 题型扩展遵循「type 字段 + switch 分派 + 专用 Renderer 组件」模式：新增题型只需在 types 中声明联合类型、JSON 中添加条目、并在 `renderQuestion` 中增加分支即可。
- 答题交互态统一使用 `'idle' | 'correct' | 'wrong' | 'disabled' | 'reveal'` 五态枚举，通过 `optionStates` 数组驱动 `MathOptionCard` 的视觉反馈，避免在组件内自行维护点击状态。
- 每日进度按 `YYYY-MM-DD` 字符串比较判定新日，`resetIfNewDay` 在会话初始化时触发，保证跨天自动重置当日进度与今日题目池。
- Python 题库生成脚本固定 `random.seed(42)` 并使用 Day 序号作为题目 ID 前缀（`ch_d{day:02d}_q{n:02d}`），确保同一份种子下每次生成的题目顺序完全一致。
