基于 Vite + React 19 + TypeScript 的单页应用，采用 `src/pages` 路由分层（`HomePage`/`LearnPage`/`MathLearnPage`/`ReviewPage`/`GemPage`/`ProfilePage`），通过 `App.tsx` 中的 `lazy()` 实现非首页页面懒加载；答题类页面（`/learn`、`/math-learn`）独立全屏布局，其余页面统一包裹在 `Layout` 组件内。

状态管理按学科拆分为独立的 Zustand store：`useLearningStore`（汉字）、`useMathLearningStore`（数学）、`useErrorBankStore`（错题本）、`useGemStore`（宝石）、`useUserStore`（用户），均使用 `zustand/middleware/persist` 持久化到 localStorage，并通过 `getTodayStr()` 判断日期切换重置进度。

题型渲染采用「数据驱动 + 专用 Renderer」模式：`types/index.ts` 定义 `QuestionType` / `MathQuestionType` 等联合类型，`data/questions.json` 与 `data/math-questions.json` 作为静态题库，`pages/MathLearnPage.tsx` 根据 `question.data.type` 分派到 `PatternRenderer`/`CountingRenderer`/`ComparisonRenderer`/`ShapeRenderer` 四个数学 Renderer，每个 Renderer 再复用 `MathOptionCard` 统一选项交互态（idle/correct/wrong/disabled/reveal）。音频层 `lib/sounds.ts` 封装 Web Audio API 合成音效与 Edge TTS 预录语音，避免运行时 TTS 延迟。

题库生成由 Python 脚本负责：`scripts/generate-chinese-questions.py` 以 PHASE1/2/3 三阶段 300 个常用字为种子，按 Day 序号确定性产出 90×10=900 道题目并写入 `src/data/questions.json`；`scripts/generate-audio.py` 调用 `edge-tts` 生成鼓励语音；`scripts/generate-char-audio.py` 批量生成汉字读音音频至 `public/audio/chars/`。部署配置 `vercel.json` + `_headers`/_redirects 用于 CDN 缓存与 SPA 重定向。
