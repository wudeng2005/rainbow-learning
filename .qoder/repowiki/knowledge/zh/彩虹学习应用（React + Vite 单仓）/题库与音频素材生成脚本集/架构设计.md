本模块是纯 Python 脚本集合，按学科/资源类型切分为独立可执行文件，彼此无相互 import：
- 题目生成器：`generate-chinese-questions.py`（PHASE1/2/3 共 300 个汉字，5 种题型 `char_to_pinyin`/`pinyin_to_char`/`char_to_pic`/`char_to_word`/`char_to_meaning`）、`generate-english-questions.py`（主题词库 THEMES + 4 种题型 `listen_pic`/`pic_word`/`phonics`/`listen_sentence`）、`generate-math-questions.py`（8 种题型通过 BUILDERS 映射表注册）。三者均使用 `random.seed(42)` 保证 Day 序号到题目的确定性输出，最终写入 `src/data/{subject}-questions.json`。
- 音频合成器：`generate-audio.py`（对错鼓励语）、`generate-char-audio.py`（300 个汉字读音）、`generate-english-audio.py`（从 english-questions.json 反推所有 word/letter/sentence 并生成到 `public/audio/en/{words,letters,sentences}/`）。全部依赖 `edge_tts.Communicate`，以 `asyncio.gather` 分批次并发避免 API 限流，且对已存在 mp3 做幂等跳过。
- 文档入口 `AUDIO.md` 作为“改什么数据 → 跑哪个脚本”的操作手册，明确输出目录 `public/audio/` 需随代码提交至 git。
依赖方向单向：脚本 → `src/data/*.json`（读）→ `public/audio/*`（写），不反向依赖应用代码。
