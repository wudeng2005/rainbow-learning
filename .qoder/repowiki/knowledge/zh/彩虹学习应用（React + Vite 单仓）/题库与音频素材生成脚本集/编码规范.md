- 每题 id 采用 `{subject}_d{day:02d}_q{n:02d}` 三段式命名（如 `ch_d01_q03`、`e_d15_q07`、`m_d60_q09`），由 day 序号与当日题号拼接而成。
- 所有生成脚本在文件顶部设置 `random.seed(42)`，确保同一份数据每次运行产出完全相同的题目序列。
- 每科按 PHASE 划分难度：Day 1-30 → level/difficulty=1，31-60 → 2，61-90 → 3，并在 daily type layout 中逐步引入新题型。
- 音频路径采用绝对 URL 形式（如 `/audio/chars/${char}.mp3`、`/audio/en/words/${word}.mp3`），由生成器与合成器共享约定而非运行时解析。
- TTS 合成统一配置 VOICE + RATE（-10%~-18%）+ PITCH（+5Hz~+8Hz）+ 可选 VOLUME，并以 `os.path.exists` 实现增量幂等，仅补录缺失文件。
- 并发调用 `edge_tts` 时按固定 batch_size（20 或 15）切片，用 `asyncio.gather(*tasks)` 批量提交并在每个批次打印进度计数。
