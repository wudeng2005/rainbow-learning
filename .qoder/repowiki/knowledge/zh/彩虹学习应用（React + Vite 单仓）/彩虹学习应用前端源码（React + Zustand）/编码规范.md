- 题目数据统一以 JSON 文件形式声明，每条记录包含 `id`、`subject`、`type`、`day`、`content`、`answer`、`options`、`difficulty` 等字段，并按 day 序号分组以实现确定性顺序出题。
- Zustand store 一律通过 `create(persist(...))` 创建，并使用 `partialize` 白名单仅持久化必要字段，避免将运行时计算结果或大对象写入磁盘。
- 学科相关组件与 store 成对出现：`components/english/` 对应 `useEnglishLearningStore`，`components/math/` 对应 `useMathLearningStore`，通用能力则放在根级 `components/` 下复用。
- 答题流程遵循 `startDailySession → submitAnswer → nextQuestion` 三步动作，`nextQuestion` 在当天最后一题完成后推进 `chineseDayIndex` 并触发 `syncManager.syncAfterSession()` 进行批量同步。
- localStorage 操作全部通过 `lib/storage.ts` 的 `getStorageItem` / `setStorageItem` 封装，统一捕获异常并静默降级，禁止在业务代码中直接调用原生 API。
