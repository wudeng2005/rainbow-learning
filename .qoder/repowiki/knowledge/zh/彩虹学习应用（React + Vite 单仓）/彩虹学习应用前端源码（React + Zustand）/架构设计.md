入口 `src/main.tsx` 通过 `createRoot` 挂载 `<App>`；`App.tsx` 使用 `react-router-dom` 的 `BrowserRouter` + `lazy()` 懒加载非首页页面，并以 `/learn`、`/math-learn`、`/english-learn` 三个独立全屏答题路由和包裹在 `<Layout />` 中的主页路由划分布局边界。

- 组件层：`components/` 下按通用组件（`Layout`、`ProgressBar`、`OptionCard`、`FeedbackOverlay`、`FloatingDecorations`、`DailyComplete`、`StarAnimation`、`UserAvatar`、`GemCounter`、`BottomNav`）与学科子目录 (`english/`、`math/`) 组织，各学科拥有独立的渲染器（如 `PhonicsRenderer`、`ArithmeticRenderer`）和反馈/进度覆盖层。
- 数据层：`data/` 存放题库 JSON（`questions.json` 含 900 道汉字题、`math-questions.json`、`english-questions.json`）及鼓励语常量；`lib/db/` 提供 Supabase 同步（由 `useLearningStore` 等 store 调用），`lib/storage.ts` 封装 localStorage 读写与日期工具，`lib/sounds.ts` 管理音频播放。
- 状态层：`store/` 中每个学科一个 Zustand store（`useLearningStore`、`useMathLearningStore`、`useEnglishLearningStore`、`useErrorBankStore`、`useGemStore`、`useUserStore`），均通过 `zustand/middleware/persist` 以 `partialize` 白名单持久化到 localStorage，并在会话结束时触发 `syncManager.syncAfterSession()` 批量同步。
- 类型层：`types/index.ts` 用 discriminated union 定义 `Question` / `MathQuestion` / `EnglishQuestion` 三大题目接口，并通过 `QuestionType`、`MathQuestionType`、`EnglishQuestionType` 区分题型，所有题目共享 `day: number` 字段用于确定性顺序出题。
- 依赖方向：pages → components → hooks/lib/store → data/types，store 单向消费 data JSON 并写回 storage/Supabase，组件不直接访问数据源。
