根目录作为单仓入口，通过 package.json 的 npm scripts 统一编排两个子模块：`scripts/` 负责在 Node 环境下用 edge-tts 生成 90×10 题的汉字/数学/英语 JSON 题库与 mp3 资源；`app_source/src/` 基于 React Router + Zustand 消费这些静态资源，按 Day 序号确定性出题并持久化错题。Vite 配置提供 `@` 路径别名指向 src，TypeScript 采用 project references 将 app 与 node 环境分离，构建时先执行 `tsc -b` 再 `vite build`，部署目标由 vercel.json 指定。
