## 样式系统概览

本项目采用 Tailwind CSS v4 + CSS Variables 主题的原子化样式方案，结合 Framer Motion 提供游戏化的交互动画，面向儿童教育场景构建明亮、活泼的视觉风格。

### 核心架构
- 样式框架: Tailwind CSS v4（通过 @tailwindcss/vite 插件集成），使用 @import "tailwindcss" 引入而非传统配置方式
- 主题定义: 在 src/index.css 中通过 @theme 块集中声明设计令牌（Design Tokens）
- 动画库: Framer Motion 负责组件级微交互，CSS @keyframes 处理全局装饰动画
- 响应式策略: 基于 Tailwind 断点 + html 字体大小媒体查询实现移动端优先

### 设计令牌体系
项目定义了完整的色彩语义系统：
- 彩虹主色: --color-rainbow-* (红/橙/黄/绿/蓝/紫) 用于品牌识别和进度指示
- 业务色: --color-gem-gold 用于宝石奖励计数
- 背景色: --color-bg-warm, --color-bg-card 用于页面/卡片背景
- 文本色: --color-text-primary, --color-text-secondary 用于主次文字层级
- 反馈色: --color-correct, --color-wrong-soft 用于答题正误反馈

### 组件样式约定
所有可交互选项卡遵循统一的状态机模式：状态包括 idle/correct/wrong/reveal/disabled，使用 spring 弹性过渡（stiffness: 500, damping: 25），点击时 whileTap scale(0.93)，悬停时 y轴位移加 scale(1.02~1.03)。

各学科选项卡通过差异化配色区分：通用版本使用粉/蓝/绿三色柔和底，数学版本使用粉/黄/绿/紫四色高饱和，英语版本使用天蓝/青/靛青/青色冷色调。

### 动画系统
全局动画集中在 index.css，分为漂浮装饰（float-slow/medium/fast + drift-slow/medium）、糖果效果（candy-fall/slow）和星星脉冲（star-pulse）三类。

### 响应式与移动端适配
基础字体 16px，大于等于768px提升至 18px；底部导航使用 pb-[env(safe-area-inset-bottom)] 适配刘海屏；所有触摸目标设置 touch-manipulation 避免双击缩放；禁用 -webkit-tap-highlight-color 消除移动端点击高亮。

### 开发者规范
1. 颜色使用: 优先使用 text-text-primary 等语义化类，而非直接写十六进制值
2. 动画复用: 新组件应复用现有 animate-float-* / animate-drift-* 类
3. 状态样式: 新增交互组件需实现 idle/correct/wrong/reveal/disabled 五态样式
4. Framer Motion: 使用 spring 类型过渡，保持 stiffness/damping 一致以获得统一手感
5. 移动端优先: 默认样式针对手机，用 md: 前缀扩展桌面端布局
