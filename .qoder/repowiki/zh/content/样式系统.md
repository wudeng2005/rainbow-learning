## 项目结构
样式系统由以下关键文件构成：
- 入口样式：在应用入口中引入全局样式，确保主题变量与基础排版优先生效
- **纯CSS启动屏幕**：在HTML入口文件中实现的启动界面，提供流畅的加载体验
- 全局样式：**现代化重构的全局样式文件**，定义完整的 CSS 变量主题、语义化颜色系统与基础排版
- 组件样式：现代化组件通过原子类与语义化变量组合实现一致的视觉风格
- 页面样式：各页面通过组件组合实现复杂的视觉效果与动画
- **数学主题样式**：数学页面专用的糖果主题样式和动画系统
- 构建配置：Vite 集成 TailwindCSS 插件，确保原子类按需生成与构建

## 核心组件
- **现代化彩虹主题色彩系统**：经过重构的完整彩虹色谱（红橙黄绿蓝紫）与辅助色彩（宝石金、卡片背景、文本颜色）构建统一的品牌视觉，支持浅色与深色模式
- **优化的现代底部导航系统**：固定定位的导航栏，支持激活状态动画、毛玻璃效果与安全区域适配，性能得到显著提升
- **增强的浮动粒子动画系统**：首页背景的无限循环粒子动画，支持多种表情符号与随机延迟，动画流畅度大幅提升
- **重构的浮动装饰动画系统**：CSS 动画关键帧定义的完整装饰动画库，包括慢速、中速、快速浮动和漂移效果，性能优化显著
- **响应式学科卡片**：灵活的学科卡片设计，支持锁定状态、徽章显示与悬停动画效果，响应式表现更佳
- **优化的进度指示器**：渐变色进度条，支持动画过渡与百分比显示，集成脉冲动画反馈，动画更加平滑
- **宝石收集动画**：SVG 宝石堆叠动画，支持多种布局模式与闪光效果，渲染性能提升
- **用户头像系统**：可点击的用户头像，支持图片与字符两种显示模式，交互体验优化
- **数学主题样式系统**：糖果王国主题的粉色和翡翠色配色方案，支持渐变背景和装饰元素
- **数学专用动画效果**：candy-fall 糖果飘落动画、数学进度条脉冲效果和反馈动画，性能优化显著
- **数学装饰元素**：MathFloatingDecorations 糖果主题浮动装饰，包含多种表情符号
- **数学反馈系统**：MathFeedbackOverlay 糖果主题反馈弹窗，支持正确和错误状态的不同样式
- **数学每日完成页面**：MathDailyComplete 糊涂主题完成界面，包含宝石奖励显示
- **数学选项卡片**：MathOptionCard 粉色和翡翠色主题卡片，支持多种状态动画
- **数学进度条**：MathProgressBar 糖果进度条，使用🍬(完成) 🍭(当前) ☆(待做) 表情符号
- **Framer Motion 动画集成**：广泛使用动画库实现流畅的交互动画效果，性能优化显著

## 架构总览

- **纯CSS启动层**：独立的启动屏幕层，提供无JavaScript依赖的快速启动体验

### 现代化彩虹主题色彩系统
- **设计理念**：通过完整的彩虹色谱（红橙黄绿蓝紫）与辅助色彩（宝石金、卡片背景、文本颜色）构建统一的品牌视觉，经过现代化重构优化

  - 状态色：正确答案绿色、错误状态紫色等，提供清晰的反馈

### 浮动粒子动画系统
- **设计理念**：首页背景的无限循环粒子动画，营造梦幻的学习氛围

## 性能考虑
- **原子类按需生成**：TailwindCSS 插件仅生成实际使用的类，减少 CSS 体积
- **SVG 动画优化**：宝石动画使用 SVG 而非 Canvas，提供更好的缩放质量和性能
- **CSS 动画性能**：浮动装饰动画使用纯 CSS 实现，避免 JavaScript 动画的性能开销
- **数学动画优化**：糖果飘落动画使用 CSS @keyframes，性能优于 JavaScript 动画
- **动画优化策略**：合理使用动画数量，浮动装饰动画使用 `pointer-events-none` 确保不影响交互
- **现代化性能优化**：通过 index.css 的大规模重构，进一步优化了动画性能和渲染效率
- **硬件加速支持**：充分利用 CSS transform 和 opacity 属性的硬件加速特性
- **组件懒加载**：页面组件按需加载，减少首屏加载时间
- **缓存策略**：本地存储用户数据，减少重复请求
- **数学页面优化**：数学页面的动画效果经过专门优化，确保在移动设备上的流畅运行
- **启动屏幕优化**：纯CSS启动屏幕无需JavaScript依赖，显著提升首屏加载速度
- **无阻塞加载**：启动屏幕与JavaScript加载并行进行，避免相互阻塞
