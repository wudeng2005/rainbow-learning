## 简介

这是一个基于 React + TypeScript + Vite 构建的儿童学习系统，名为"快乐学堂"。该系统现已扩展为双学科学习平台，专注于汉字学习和数学学习，提供互动式的学习体验，包含每日学习计划、错题复习、宝石奖励机制等功能。

系统采用现代化的技术栈，包括：
- React 19.2.6 用于构建用户界面
- TypeScript 提供类型安全
- Vite 8.0.12 作为构建工具
- Zustand 5.0.14 作为状态管理库
- Supabase 2.108.2 作为后端服务
- Framer Motion 12.40.0 用于动画效果
- TailwindCSS 4.3.1 用于样式设计

**最新更新亮点**
- **进度条系统全面重构** - 引入数学糖果主题和英语海洋主题的彩色进度条，配合角色动画
- **庆祝系统增强** - 增加彩虹特效、星星评分系统和角色跳跃动画
- **选项卡片物理反馈** - 获得真实的物理按压反馈效果
- **核心页面重构** - HomePage和LearnPage等重大重构，提升用户体验
- **导航系统优化** - 重新设计的导航结构，更直观的页面跳转
- **内容组织改进** - 优化的学习内容展示和组织方式
- **视觉设计增强** - 增强的界面视觉效果和动画表现
- **响应式布局优化** - 改进的移动端和桌面端适配效果

### 学习管理系统

系统的核心是学习管理系统，通过 Zustand 状态管理实现。主要包含以下状态存储：

#### 中文学习存储 (useLearningStore)
- 管理每日中文学习进度
- 控制题目序列和当前索引
- 处理答题结果和统计
- 实现题目随机抽取和去重

#### 数学学习存储 (useMathLearningStore)
- 管理每日数学学习进度
- 支持四种数学题型的题目序列
- 数学学习专用的状态管理和统计
- 数学题目随机抽取和去重机制

#### 宝石存储 (useGemStore)
- 管理用户获得的宝石数量
- 记录宝石获取历史
- 支持宝石消费和统计
- 支持数学学习的专属宝石奖励

#### 错题本存储 (useErrorBankStore)
- 跟踪用户的错误题目
- 实现间隔重复算法
- 管理复习计划和进度

#### 用户存储 (useUserStore)
- 管理用户基本信息
- 支持头像和名称更新
- 同步用户设置到云端
- 新增头像自动迁移功能，确保旧emoji头像与新图片头像兼容性
